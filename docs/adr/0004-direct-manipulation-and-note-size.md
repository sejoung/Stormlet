# ADR 0004: 직접 조작, 메모 크기와 자동 글자 맞춤

- 상태: 채택
- 날짜: 2026-11-06
- 관련: ADR 0002, 0003

## 배경

선택과 이동을 별도 모드로 두면 같은 보드에서 작업할 때 도구를 반복해서 바꿔야 한다. 메모를 겹쳐 배치하고 크기를 바꿀 수 있어야 하며, 짧은 문장은 크게, 긴 문장은 작게 표시해 종이 면적을 활용해야 한다.

## 결정

1. **상황에 따른 조작**: 메모를 누르면 선택하고 끌면 이동한다. 빈 배경을 끌면 보드가 이동한다. Shift+드래그는 기존 선택에 사각형 선택을 추가한다. 별도의 이동 모드는 없다.
2. **우클릭 메뉴**: 메모의 앞뒤 순서, 크기 프리셋과 수치 입력, 편집·삭제를 제공한다. 이미 선택한 메모에서 열면 선택 전체에 적용한다. Shift+F10, 방향키, Escape도 지원하고 텍스트 편집 중에는 브라우저의 기본 메뉴를 유지한다.
3. **명시적 앞뒤 순서**: 이동은 위치만 바꾼다. 앞으로·뒤로 보내기는 선택한 그룹의 내부 순서를 유지한다. 도메인의 순서 값은 음수도 가능하며 화면은 정렬 순위를 양수 z-index로 변환한다.
4. **개별 크기**: 메모의 `width`, `height`는 각각 독립 필드다. 기본은 160 × 120, 허용 범위는 너비 80–1280, 높이 60–960이다. 모서리 드래그는 미리보기만 바꾸다가 놓을 때 하나의 편집으로 커밋한다. 취소하면 원래 크기를 유지한다.
5. **내용 중심 표시**: 이벤트 스토밍에서도 종류 라벨은 메모에 그리지 않는다. 종류는 데이터, 팔레트와 접근성 이름에 유지한다. 글자 크기는 실제 DOM의 줄바꿈과 가로·세로 공간을 측정해 8–144px 범위에서 맞춘다. 편집 중에도 같은 맞춤을 적용한다. 최소 크기에서도 넘치는 긴 내용은 스크롤로 읽을 수 있다.
6. **포맷 버전 3**: 개별 크기를 저장한다. 버전 1·2는 원래의 160 × 120 크기를 부여해 읽는다. 기존 필드와 역패치 구조를 유지하므로 크기와 순서를 따로 되돌릴 수 있다.

## 결과

별도의 조작 모드를 기억할 필요가 줄어든다. 크기 변경과 앞뒤 순서 변경은 저장·동기화·실행 취소의 기존 경로를 따른다. 폰트 크기는 저장 데이터가 아닌 내용과 크기에서 파생한 화면 상태이며, 레이아웃을 측정할 수 없는 환경에서는 글자 폭을 추정한다.
