# ADR 0012: 배치 편의 기능

- 상태: 채택
- 날짜: 2026-11-09
- 관련: [직접 조작과 메모 크기](0004-direct-manipulation-and-note-size.md), [도구별 기본값](0007-creation-defaults.md)

## 배경

위치 맞춤 가이드는 있었지만 크기·간격을 맞추거나, 여러 메모를 한 번에 크기 조절하거나, 키보드로 정렬하는 수단이 없었다. 워크숍 중에는 마우스를 오가지 않고 메모를 빠르게 이어 쓰고 정리할 수 있어야 한다.

## 결정

1. **스냅 우선순위**: 이동할 때는 가장자리·가운데 맞춤, 같은 간격, 격자 순서로 화면 8px 안의 가장 가까운 값에 붙는다. 맞춤 대상은 다른 포스트잇과 프레임 모두이고, 같은 간격·같은 크기는 같은 종류끼리(메모는 메모, 프레임은 프레임)만 본다. 프레임을 옮길 때는 함께 움직이는 내용을, 크기를 바꿀 때는 프레임 자신만 대상에서 뺀다. 같은 간격은 두 이웃 사이 가운데, 또는 이웃이 이미 가진 간격을 한 번 더 반복하는 위치다. Ctrl/Cmd를 누른 채 끌면 스냅하지 않는다.
2. **네 모서리 크기 조절**: 메모 하나만 선택하면 네 모서리에 핸들을 보이고 반대쪽 모서리를 고정한다. 오른쪽 아래 핸들만 키보드 포커스와 방향키 조절을 받는다. 크기 조절 중에는 다른 메모의 크기와 같아지는 값을 가장자리보다 먼저 잡고, 같은 크기의 메모(가까운 4개까지)와 현재 크기를 표시한다. Shift는 비율을 유지하며 이때는 스냅하지 않는다.
3. **선택 영역 크기 조절**: 여러 메모를 선택하면 경계 상자의 모서리로 전체를 비례 확대·축소한다. 가장 작은 메모가 최소 크기, 가장 큰 메모가 최대 크기에 닿으면 멈춘다. 잠긴 메모가 섞이면 핸들을 숨긴다. 상자의 오른쪽 아래 핸들은 방향키로도 전체 크기를 바꾼다. 위치와 크기는 `placeStickies` 한 번의 편집으로 저장한다.
4. **크기 맞춤**: 너비·높이·크기 같게는 선택 중 가장 큰 값을 따른다. 글자가 넘치지 않고 선택 순서와 무관하기 때문이다.
5. **정렬 단축키**: Option/Alt + A·H·D·W·V·S로 정렬하고, Shift를 더하면 H·V로 간격을 맞춘다. Mac의 Option 입력은 기호가 되므로 `event.code`(물리 키)로 판별한다.
6. **스타일 복사**: ⌘/Ctrl + Option/Alt + C·V로 색과 글자 서식(굵게·기울임·밑줄·정렬·글자 크기)을 옮긴다. 크기와 내용은 옮기지 않는다. 복사한 스타일은 브라우저 저장소(`stormlet.copied-style`)에 두어 새로고침과 탭을 넘어 유지하고, 읽을 때 보드 파일과 같은 규칙으로 검증한다. 보드와 실행 취소 기록에는 넣지 않는다. Windows의 AltGr는 Ctrl+Alt로 전달되어 문자를 입력하는 키이므로, AltGraph가 눌린 동안에는 보드 단축키를 실행하지 않는다.
7. **이어 쓰기**: 편집 중 Tab은 오른쪽, ⌘/Ctrl + Enter는 아래에 같은 크기·스타일의 새 메모를 만들고 바로 편집한다. 자리가 차 있으면 같은 방향으로 더 간다. 원래 메모의 글과 새 메모는 실행 취소 한 번으로 함께 되돌린다.
8. **격자**: 보기 메뉴에서 격자 표시와 격자 맞춤을 따로 켠다. 격자는 20 보드 픽셀 간격으로 이동·확대를 따라가며, 화면에서 8px보다 촘촘하면 그리지 않는다. 두 설정은 브라우저에 저장하며 보드 파일은 바꾸지 않는다.
9. **팔레트에서 끌어 놓기**: 포스트잇 색상 칸을 포인터 이벤트로 끌어 보드에 놓으면 그 색의 메모를 만든다. 기본 드래그 앤 드롭 대신 포인터를 쓰므로 터치에서도 동작한다. 패널 위에 놓으면 만들지 않으며 기본 색은 바꾸지 않는다.
10. **연결선 검정과 포맷 버전 9**: 연결선 색에 검정을 더한다. 어두운 테마에서는 밝은 잉크로 그린다. 저장 형식을 버전 9로 올려, 이전 빌드는 검정 선이 든 파일을 손상된 파일이 아니라 더 새 버전의 파일로 거부한다. 버전 1–8도 계속 읽으며, 버전 8로 저장된 검정 선(버전을 올리기 전 빌드에서 만든 파일)도 받아들인다.

## 결과

맞춤·간격·크기 조절이 같은 스냅 규칙을 따른다. 크기 조절 제스처는 메모 하나와 선택 영역을 같은 경로로 처리한다. 단축키·우클릭 메뉴·선택 도구 막대가 같은 명령을 실행한다.
