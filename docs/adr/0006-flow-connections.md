# ADR 0006: 포스트잇 사이의 흐름 연결선

- 상태: 채택
- 날짜: 2026-11-06
- 선행: [포스트잇 조작 흐름](0005-sticky-workflow.md)

## 결정

1. 왼쪽 연결선 도구와 `L`로 시작·끝 메모를 차례로 클릭하거나, 선택한 메모의 네 연결점을 끌어 선을 만든다. 연결점은 키보드로도 시작하고 다른 메모에서 Enter로 완료할 수 있다. Escape·포인터 취소·다른 도구 선택은 미완료 선을 버린다.
2. 연결 끝점은 메모 ID와 부착 면 또는 자유 좌표로 저장한다. 자동 부착은 메모의 위치에 따라 경계 면을 고르고, 직접 연결점을 사용하면 그 면에 고정한다. 선의 실제 위치는 드래그·크기 조절 중의 임시 메모 위치까지 반영해 계산한다.
3. 기본은 끝에 화살표가 있는 꺾인 선이다. 직선·꺾인 선·곡선, 양 끝 화살표, 색상·두께·점선, 연결선 하나당 설명 하나를 편집할 수 있다. 선 더블클릭 또는 Enter로 설명 입력에 초점을 옮긴다.
4. 선택한 선의 끝점을 끌어 다른 메모에 연결하거나 자유 좌표로 분리한다. Ctrl/Cmd는 메모 스냅을 해제하고 Shift는 끝점을 45도 단위로 제한한다. 잠금은 선의 편집·삭제를 막으며 연결된 메모의 이동은 허용한다.
5. 연결선은 메모와 별도의 ID 맵이다. 추가·필드 수정·삭제 패치는 기존 기록과 저장소를 사용한다. 메모 삭제는 관련 선을 함께 지우고, 한 번의 실행 취소로 모두 복원한다. 여러 메모 복제·복사에서는 양쪽 메모가 선택된 내부 연결선만 새 ID로 복제한다.
6. 저장 형식 버전 6에 연결선 배열을 추가하며 버전 1–5를 계속 읽는다. 파일을 읽을 때 좌표·스타일·메모 참조를 검증한다. 연결선이 없는 기존 보드는 연결선 속성을 추가하지 않는다.
7. SVG는 보드 좌표계에서 메모 뒤에 선을 그리고 선택 핸들은 메모 앞에 그린다. 투명한 넓은 선을 선택 영역으로 사용하며 확대 비율에 맞춰 끝점 핸들·선택 영역의 화면 크기를 유지한다. 화면 맞춤에는 자유 연결선 범위도 포함한다.

## 검증

연결선 CRUD·잠금·참조 유효성·실행 취소, 메모 삭제와 연결선의 동시 복원, 내부 연결선 복제, 파일 왕복과 이전 버전 호환성을 확인한다. 기하 계산은 모든 연결 면과 선 종류, 이동·크기 변경, 스냅과 방향 제한을 포함한다. UI 테스트는 도구 클릭·연결점 드래그·끝점 재연결·라벨 편집·키보드 조작·파일 저장·흐름 전체 붙여넣기를 포함한다.
