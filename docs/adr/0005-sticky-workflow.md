# ADR 0005: 포스트잇 중심의 조작 흐름과 문맥 도구

- 상태: 채택
- 날짜: 2026-11-06
- 선행: [ADR 0004](0004-direct-manipulation-and-note-size.md)

## 결정

Miro의 포스트잇 생성·선택·입력·정리 흐름을 참고해 기능과 화면을 함께 확장한다. Stormlet의 로컬 우선 저장소, 이벤트 스토밍 팔레트와 패치 기반 실행 취소 구조는 유지한다.

1. 기본 도구에서 배경 드래그는 영역 선택이다. 손 도구, Space+드래그, 가운데 버튼 드래그는 보드 이동이다. 빈 보드 더블클릭 생성은 제거한 상태를 유지한다.
2. 선택한 메모에서 바로 입력하거나 Enter·더블클릭으로 편집한다. Enter/Escape는 완료, Shift+Enter는 줄바꿈이다. IME 조합 중 키 입력은 편집을 완료하지 않는다.
3. 왼쪽 팔레트와 보드 작업 막대를 띄우고, 문맥 도구를 선택한 메모 가까이에 표시한다. 메모가 위쪽 경계에 있으면 도구를 아래에 배치한다. 작은 화면에서는 팔레트를 압축한다.
4. 서식은 메모 전체에 적용한다. 굵게·기울임·밑줄·정렬·자동/수동 글자 크기와 정사각형·직사각형 전환을 지원한다. 입력창만 스크롤하며 긴 메모의 휠 동작은 보드 확대를 막는다.
5. 복제·정렬·대량 생성·그룹·잠금은 각각 하나의 패치 묶음으로 실행하고 한 번에 취소한다. Alt/Option+드래그 복제는 놓기 전까지 원본을 변경하지 않는다. 정렬은 그룹 내부의 상대 위치를 유지한다.
6. 복사에는 텍스트와 `application/x-stormlet`을 함께 기록한다. 보드에 붙일 때 구조화된 데이터는 검증 후 새 ID로 복제하고, 텍스트·스프레드시트 데이터는 각각 메모로 변환한다. 텍스트 편집 중에는 기본 클립보드를 유지한다.
7. 태그는 메모당 8개, 각 30자다. 새 입력은 메모당 3,000자다. 스프레드시트 붙여넣기는 50행 × 100열까지 처리하며 따옴표로 감싼 여러 줄 셀을 보존한다. 대량 입력은 최대 5,000개를 미리 보고 붙인다.
8. 작성자는 브라우저에 저장한 이름을 사용한다. 반응은 이 이름으로 토글하고 다른 이름의 반응을 지우지 않는다. 계정 인증이나 서버 기반 협업은 추가하지 않는다.
9. 저장 형식 버전 4는 선택적인 서식·태그·작성자·반응·그룹·잠금 필드를 추가한다. 버전 1–3을 읽고, 알 수 없는 미래 버전은 거부한다. 이전 보드로 교체하거나 실행 취소할 때 없는 선택 필드는 실제로 제거한다.

## 검증

도메인 명령, 저장 형식 호환성, 스프레드시트 파싱과 화면 맞춤을 검증한다. UI 테스트는 한글 조합, 작성 중 복제·잠금, 그룹 이동, 대량 생성의 실행 취소, 구조화된 복사·붙여넣기와 태그 검색을 포함한다. 실제 브라우저의 타이포그래피·스크롤바·포인터 캡처는 별도의 화면 검증 대상이다.
