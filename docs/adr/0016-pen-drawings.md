# 0016. 펜 그림

상태: 승인됨

## 맥락

보드와 포스트잇 위에 손으로 표시할 수 있어야 한다. 자유 그리기, 색상과 굵기를 제공하며 형광펜, 지우개, 스마트 도형 인식은 범위에 넣지 않는다.

## 결정

- 왼쪽 펜 버튼과 `P`로 펜을 켜고 연속해서 그린다. `V`는 선택 도구, `Esc`는 펜 종료다. 미완성 획은 Esc, 포인터 취소, 캡처 해제, 창 포커스 상실 또는 도구 전환으로 취소한다.
- Pointer Events로 마우스·트랙패드·터치·스타일러스를 처리한다. 포인터 소유권을 기존 캔버스 제스처와 공유하여 두 번째 손가락이 획을 바꾸지 못하게 한다. Space와 휠 버튼으로 임시 이동할 수 있다.
- 기본은 검정 3px이다. 7색 팔레트, 사용자 지정 색상과 1–16px 굵기를 제공하며 생성 기본값 어댑터로 설정을 저장한다. 한 획의 스타일은 시작할 때 고정한다.
- `stickies` 컬렉션의 `objectType: 'drawing'`으로 저장한다. `ink`는 경계 상자에 대한 정규화 좌표 배열이고, `strokeColor`와 `strokeWidth`는 독립 필드다. 텍스트 편집과 포스트잇 배경은 적용하지 않는다. 그린 선을 선택하여 색상과 굵기를 다시 바꿀 수 있다.
- 그리는 동안 임시 미리보기만 표시하고 포인터를 놓을 때 한 번의 추가 패치로 커밋한다. 클릭은 점으로 저장한다. 이동·크기 조절·복사·프레임 포함·그룹·잠금·삭제·실행 취소와 Drive 병합은 기존 객체 명령을 공유한다.
- 화면·복제 미리보기·미니맵·이미지 내보내기가 같은 곡선 경로 함수를 쓴다. 선택 시 빈 경계 상자가 아니라 실제 획을 클릭한다. 크기 조절은 정규화 좌표를 유지하고 선 굵기는 유지한다.
- 파일은 버전 11로 올리고 버전 1–10을 계속 읽는다. 색상, 굵기, 유한 좌표와 점 개수를 검증한다. 한 획이 20,000점을 넘으면 표본을 줄이며, 그림에는 포스트잇의 최소·최대 크기를 적용하지 않는다.

## 결과

그림이 기존 보드 저장, 클립보드, 이미지 내보내기와 동기화에 참여한다. 필압, 부분 지우기, 획 단위 지우개와 도형 인식은 이후 요구가 생기면 다룬다.
