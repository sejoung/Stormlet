# ADR 0013: PNG·SVG 이미지 내보내기

- 상태: 채택
- 날짜: 2026-11-09
- 관련: [직접 조작과 메모 크기](0004-direct-manipulation-and-note-size.md), [배치 편의 기능](0012-layout-conveniences.md)

## 배경

보드를 문서·메신저·위키에 올리려면 그림 파일이 필요하다. `.stormlet` 파일은 앱에서만 열린다.

## 결정

1. **모델에서 SVG를 그린다**: 화면 DOM을 캡처하지 않고 보드 데이터로 독립 SVG를 만든다. 선택 표시·손잡이·도구 막대 같은 편집 장치가 섞이지 않고, 화면 밖 내용과 확대 수준에 상관없이 보드 전체가 같은 모습으로 나온다. 순서는 프레임(넓은 것부터), 연결선, 메모(쌓임 순서)이며 반응 배지도 그린다.
2. **글자는 화면과 같게 맞춘다**: 메모 글자는 편집기와 같은 `fitNoteFont`로 크기를 정하고, 줄바꿈은 `pre-wrap`·`overflow-wrap: anywhere`처럼 공백과 한중일 글자 사이에서 끊는다. 너비는 브라우저 캔버스로 같은 글꼴을 재며, 기준 크기에서 한 번 재고 비례로 환산해 캐시한다.
3. **밝은 테마, 흰 배경**: 편집기 테마와 관계없이 밝은 테마 색으로 그린다. 그래서 어두운 테마에서 밝게 보이는 검정 연결선도 내보낸 그림에서는 검정이다.
4. **PNG는 SVG를 래스터화한다**: 같은 SVG를 이미지로 읽어 캔버스에 2배 밀도로 그린 뒤 PNG로 인코딩한다. 브라우저의 캔버스 한도(한 변 16,384px, 넓이 약 1억 2천만 픽셀) 안에 들도록 큰 보드는 밀도를 낮춘다.
5. **배치**: SVG 생성은 색 정의를 쓰므로 `components/export`에 두고, 캔버스 측정·래스터화·다운로드는 `adapters/files`에 둔다. 파일 이름은 `.stormlet`과 같이 보드 이름을 따른다. 빈 보드에서는 메뉴를 끈다.

## 결과

내보낸 SVG는 웹 글꼴 없이 시스템 글꼴 목록을 지정하므로, 다른 컴퓨터에서 열면 글꼴이 바뀌어 줄바꿈이 조금 달라질 수 있다. 정확한 모양이 필요하면 PNG를 쓴다. 지금은 보드 전체만 내보내며, 선택 영역만 내보내기는 이후 과제다.
