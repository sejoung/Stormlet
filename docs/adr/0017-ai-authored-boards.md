# 0017. AI가 만드는 보드

상태: 승인됨

## 맥락

`.stormlet` 파일은 읽을 수 있는 JSON이고 보드 모델은 평평한 맵이라([ADR 0002](0002-collaboration-ready-model.md)) AI가 보드를 만들고 읽기에 알맞다. 다만 AI는 좌표를 계산하다 메모를 겹치거나 프레임 밖으로 내보내기 쉽고, 메모가 어느 프레임에 속하는지는 좌표로 정해진다. 사용자는 `.stormlet` 파일만 알면 되어야 하고, 따로 설치할 도구 없이 스킬 하나로 Claude Code, Codex, claude.ai, ChatGPT 어디서든 쓸 수 있어야 한다. 서버 없이 브라우저에서만 동작한다는 원칙([ADR 0001](0001-layered-local-first.md))은 유지한다.

## 결정

- **파일 형식 버전 12, 초안.** 별도 형식을 두지 않고 `.stormlet`이 좌표 없는 파일도 받는다. 버전 12부터 포스트잇의 `x`, `y`, `z`, `width`, `height`, `kind`, `color`, `text`를 생략할 수 있다. 프레임은 위치, 크기, 제목, 색상, 테두리, 잠금을, 연결선은 ID와 스타일을 생략할 수 있다. 생략한 값은 새로 만들 때의 기본값을 쓴다. 그림은 획이 상자에 대한 상대 좌표라서 상자를 생략할 수 없다.
- **배치 힌트.** 초안의 포스트잇은 `frame`으로 들어갈 프레임을, 프레임은 `layout`(`grid`, `column`, `row`)으로 배치 방식을 적는다. 연결선의 끝은 `"k1"`처럼 ID만 적을 수 있고, 연결점은 `auto`가 된다. 힌트는 파일을 읽을 때만 쓰고 보드 모델에는 넣지 않으므로 평평한 맵과 필드 단위 병합이 그대로다.
- **배치는 읽을 때 한 번.** `domain/layout/auto-layout.ts`가 위치 없는 객체만 배치한다. 위치가 있는 객체는 그대로 둔다. 이 함수는 결정적인 순수 함수라 같은 파일은 언제 열어도 같은 모습이다. 위치 있는 객체 아래, 또는 왼쪽 위에서 시작해 다음 순서로 놓는다.
  - 프레임 밖 텍스트는 제목처럼 위에 쌓는다.
  - 위치 없는 프레임은 한 줄로 놓고, 높이를 주지 않은 프레임끼리 높이를 맞춘다.
  - 프레임의 포스트잇은 가장 큰 메모 크기의 격자에 40px 여백을 두고 넣는다. 프레임은 내용에 맞춰 커진다.
  - 프레임 밖 포스트잇은 그 아래 격자로 놓는다.
- **저장은 항상 완전한 형태.** 앱이 저장하는 파일은 모든 필드를 채운 버전 12다. 버전 1–11을 계속 읽고, 버전 11 이하에서는 좌표 생략과 힌트를 받지 않는다.
- **드롭과 붙여넣기로 열기.** 페이지 어디에든 파일을 끌어다 놓으면 **파일 → 열기**와 같은 경로로 연다. 실행 취소할 수 있고, Drive 파일은 먼저 저장하고 연결을 끊는다. 파일을 실은 드래그에만 반응하므로 메모 이동, 색상 칸 드래그와 편집기 안의 텍스트 드래그는 그대로다. 파일을 만들 수 없는 AI는 JSON을 코드 블록으로 보여 주므로, `"format": "stormlet"`이 든 JSON 텍스트를 보드에 붙여넣어도(Markdown 코드 울타리 포함) 같은 방식으로 연다. 다른 텍스트 붙여넣기와 앱 안의 복사·붙여넣기는 바뀌지 않는다.
- **스킬은 한 원본.** `skills/stormlet/`이 Agent Skills 표준의 스킬이다. `SKILL.md`, 형식 레퍼런스, 좌표 없는 예시 보드 세 개가 들어 있다. 스크립트 없이 지침과 예시만 담아 어느 에이전트에서나 같은 내용을 쓴다. 배포 경로는 다음과 같다.
  - Claude Code: 저장소 루트의 `.claude-plugin/` 마켓플레이스와 플러그인
  - Codex, Cursor 등: `npx skills add sejoung/Stormlet`이나 각 에이전트의 스킬 폴더
  - claude.ai, ChatGPT Business·Enterprise·Edu: 빌드가 만드는 `skill/stormlet-skill.zip`
  - ChatGPT 개인 요금제처럼 스킬 업로드가 없는 채팅: 같은 원본에서 만드는 `skill/stormlet-prompt.md`
- **원본과 코드가 어긋나지 않게.** 단위 테스트가 다음을 확인한다.
  - 스킬 예시가 파서를 통과하고 겹침 없이 프레임 안에 배치되는지
  - 스킬이 가르치는 버전, 색상, 레이아웃, 연결선 값이 코드의 목록과 같은지
  - zip이 원본 파일 그대로인지

## 결과

AI는 의미 구조만 쓰고, 사용자는 받은 파일을 끌어다 놓거나 JSON을 붙여넣어 바로 연다. 설치할 도구나 서버가 없다. 형식이 바뀌면 같은 변경에서 스킬 테스트가 실패하므로 스킬도 함께 고친다.

버전 12 파일은 이전 빌드에서 열리지 않는다. 열린 보드를 AI가 실시간으로 고치는 MCP 연동은 다루지 않는다. 그런 연동은 협업용 `BoardStore`와 함께 다룬다.
