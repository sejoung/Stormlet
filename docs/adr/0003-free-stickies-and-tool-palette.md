# ADR 0003: 자유 포스트잇과 좌측 도구 팔레트

- 상태: 채택
- 날짜: 2026-11-06
- 후속: 조작 방식과 저장 포맷은 [ADR 0004](0004-direct-manipulation-and-note-size.md)에서 갱신

## 배경

포스트잇은 아이디어 정리와 회고에도 쓸 수 있다. 모든 메모에 이벤트 스토밍의 종류를 요구하면 사용 목적이 좁아진다. 더블클릭만으로 추가하는 동작도 처음 쓰는 사람이 발견하기 어렵다.

## 결정

1. **색과 의미 분리**: `color`와 `kind`는 독립 필드다. 일반 메모는 `kind: null`이다. 자유 팔레트로 기존 메모를 재색칠해도 의미는 유지한다.
2. **이벤트 스토밍은 팔레트 프리셋**: 기본 팔레트는 자유 색상이다. 이벤트 스토밍 팔레트를 고르면 기존 8가지 종류와 관례의 색으로 추가하거나 선택한 메모의 종류를 지정한다. 팔레트 전환만으로 보드를 수정하지 않는다.
3. **상단과 좌측 역할 분리**: 상단에는 파일, 기록과 팔레트 전환을 두고 좌측에는 선택, 이동과 색상 포스트잇을 둔다.
4. **드래그 배치**: 포인터 캡처로 마우스, 펜과 터치 동작을 처리한다. 확대·이동 상태를 반영한 미리보기를 보이고, 유효한 보드 영역에 놓았을 때만 한 번 추가한다. 영역 밖 드롭, 포인터 취소와 Escape는 메모를 만들지 않는다.
5. **대체 입력**: 색 선택 후 보드 클릭, 더블클릭과 키보드로 누를 수 있는 가운데 추가 버튼도 제공한다. 배치 후에는 선택 도구로 돌아간다.
6. **포맷 버전 2**: 색 필드를 저장하고 종류의 null 값을 허용한다. 버전 1은 기존 종류에서 색을 유도해 읽는다. 브라우저 저장소도 같은 파서를 사용한다.

## 결과

기존 패치와 역패치 구조를 그대로 사용한다. 색과 의미를 별도로 동기화하고 되돌릴 수 있다. 팔레트, 도구, 미리보기와 뷰포트는 편집기의 임시 상태다. 버전 2 파일은 이전 앱에서 열 수 없으며, 이전 앱은 파일을 자르지 않고 거부한다.
