# 0015. 배경 없는 텍스트

상태: 승인됨

## 맥락

보드의 제목, 설명, 주석을 포스트잇 배경 없이 적을 수 있어야 한다. 기본 서식과 편집에 집중하며 링크와 부분별 리치 텍스트는 범위에 넣지 않는다.

## 결정

- 왼쪽 텍스트 도구와 `T`, 캔버스 메뉴로 텍스트 상자를 추가한다. 더블클릭 또는 선택 후 Enter로 다시 편집한다.
- Enter는 줄바꿈, Esc와 Ctrl/Cmd+Enter는 완료다. 한글 조합 중인 키는 편집 완료로 취급하지 않는다. 빈 텍스트로 편집을 마치면 상자를 삭제한다.
- 텍스트 상자 전체에 굵게, 기울임, 밑줄, 정렬, 글자 크기와 색을 적용한다. 포스트잇과 같은 맞춤 계산으로 글자가 상자를 넘지 않으며 크기 조절도 가능하다. 기본 글자 크기는 Auto로, 내용과 상자 크기에 맞춘다.
- 텍스트의 안쪽 여백은 4px, 최소 크기는 16×16으로 포스트잇의 12px·80×60 제한과 구분한다. 드래그, 키보드, 직접 크기 입력과 파일 검증에 동일한 제한을 적용한다. 여러 객체를 함께 줄일 때는 각각의 최소 크기를 지킨다.
- 입력을 마치면 브라우저에서 측정한 가장 긴 줄과 실제 줄 높이에 맞춰 불필요한 가로·세로 공간을 줄인다. 확대·축소를 보정하고, 상단과 왼쪽·가운데·오른쪽 정렬 기준점을 유지한다. 내용과 크기를 한 번에 실행 취소한다. 화면과 이미지 내보내기는 같은 여백과 글자 맞춤 계산을 쓴다.
- `stickies` 컬렉션의 선택적 `objectType: 'text'`로 구분한다. 위치, 크기, 쌓기 순서, 그룹, 잠금, 복제, 프레임 포함 여부와 연결선은 기존 명령과 패치를 공유한다. 속성이 없는 기존 객체는 계속 포스트잇이다.
- `textColor`는 검증된 팔레트 이름이며 기본값은 테마를 따른다. 이미지로 내보낼 때 기본 글자는 밝은 테마 기준으로 그리며 배경과 그림자는 그리지 않는다.
- 저장 형식은 버전 10으로 올린다. 버전 1–9를 계속 읽고, 이전 앱은 새 파일을 거부하여 텍스트를 포스트잇으로 잘못 표시하지 않는다.

## 결과

독립 텍스트가 브라우저 저장, 파일, 클립보드, 실행 취소, Drive의 필드 단위 병합에 같은 모델로 참여한다. 내부 컬렉션 이름은 호환성을 위해 유지한다. 회전, 글꼴 선택, 부분별 서식, 링크와 목록 자동 서식은 이후 요구가 생기면 다룬다.
