# ADR 0007: 도구별 기본값 선택 패널

- 상태: 채택
- 날짜: 2026-11-07
- 선행: [포스트잇 조작](0005-sticky-workflow.md), [연결선](0006-flow-connections.md)

## 결정

왼쪽 포스트잇·연결선 도구를 누르면 옆에 설정 패널을 연다. 포스트잇은 16색을 두 열로 보여주고, 연결선은 선·화살표·꺾인 화살표·곡선 화살표와 색상·두께·점선을 고른다. 기본값은 노란 메모와 끝 화살표가 있는 꺾인 선이다.

선택한 값은 다음 생성 동작에 적용한다. 메모의 보드 클릭·가운데 추가·대량 입력·텍스트 붙여넣기, 연결선의 도구 클릭·연결점 드래그에서 같은 기본값을 사용한다. 복제와 구조화된 붙여넣기는 원본 서식을 보존한다. 설정 변경은 보드의 편집 기록에 넣지 않으며 기존 항목은 수정하지 않는다.

기본값은 `stormlet.creation-defaults`로 브라우저에 저장한다. 읽을 때 색·선 종류·두께·불리언을 검증하고 잘못된 값은 기본값으로 복구한다. 보드 파일의 버전과 데이터 구조는 바꾸지 않는다.

설정 패널은 같은 도구를 다시 누르거나 닫기·Esc·바깥 클릭·다른 도구 선택으로 닫는다. 키보드로 열었을 때도 현재 기본 선택에 초점을 두고, 선택 항목 사이에서 방향키를 사용할 수 있게 한다. Esc는 생성 모드를 끝내고 원래 도구 버튼에 초점을 돌린다.

꺾인 선은 기존 경로의 꼭짓점 양쪽을 최대 12 보드 픽셀씩 줄이고 이차 곡선으로 잇는다. 짧은 구간에서는 구간 길이의 절반까지로 반지름을 제한한다. 끝점·부착 면·연결 관계를 유지하며 기존 꺾인 선도 같은 방식으로 그린다.

## 검증

패널 열기·닫기·키보드 이동, 기본 색상과 선 스타일의 생성·미리보기 반영, 기존 항목 보존, 대량 입력, 재접속 후 설정 복원, 잘못된 설정 복구를 확인한다. 경로 계산은 짧은 구간·중복 좌표·일직선 구간에서 끝점을 보존하고 유효한 SVG 경로를 생성하는지 확인한다.
